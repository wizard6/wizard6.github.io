* 文件在哪
- 数据文件：=data/reading.org=
- 本说明：=data/reading-guide.org=
- 改 =reading.org= 后刷新「读书」窗口即可；顶部「统计」由程序自动生成，不必手写。

* 怎么写一条书
用二级标题，前面加状态关键字：

#+begin_example
** READING 书名 :标签1:标签2:
:PROPERTIES:
:LAST: 2026-09-15
:WORDS: 12000
:DURATION: 3h20m
:PROGRESS: 30%
:END:
可选备注、摘录、章节进度……
#+end_example

* 状态关键字（TODO）
| 关键字 | 含义 |
|--------+------|
| READING | 正在读 |
| NEXT    | 下一本 / 准备读 |
| TODO    | 想读（书单） |
| WAIT    | 暂停 / 等书 |
| DONE    | 已读完 |
| CANCELLED | 放弃 |

* 标签
写在标题行末尾，两侧冒号：

=** DONE 书名 <2026-08-20> :随笔:推荐:=

常用示例：=:读书:= =:书单:= =:经典:= =:游戏:= =:小说:=

* 属性（PROPERTIES）
写在标题正下方的抽屉里，= :END: = 收尾。

| 属性 | 说明 | 示例 |
|------+------+------|
| WORDS / 字数 | 已读或全书字数 | =12000= 或 =1.2万= |
| DURATION / 时长 | 阅读时长 | =90m= =3h20m= =1:30= =18h= |
| LAST | 最近阅读日 | =2026-09-15= |
| CLOSED | 读完日期 | =2026-08-20= |
| DATE | 通用日期 | =2026-09-01= |
| PROGRESS | 进度（可选） | =42%= |

* 日期
两种都行：
1. 标题里写时间戳：=** DONE 书名 <2026-08-20>=
2. 或在 PROPERTIES 里写 =:LAST:= / =:CLOSED:=

近 30 天统计优先看这些日期。

* 推荐结构（一级标题）
#+begin_example
* 在读 :读书:
* 想读 :书单:
* 已读 :归档:
* 笔记摘录
#+end_example

书放在对应一级标题下面用 =**= 写；笔记可挂在「笔记摘录」下。

* 统计会算什么
引擎会自动汇总：
- 条目数、READING / DONE 等计数
- 总字数、总时长
- 在读 / 已读完 / 近 30 天 的字数与时长
- 按条目标字数列表

未填 =WORDS= / =DURATION= 的条目按 0 计。

* 注意
- 不要手改窗口里自动生成的「统计」段；只维护 =reading.org= 正文。
- 需要我代写条目时：直接发书名、状态、字数、时长、日期、标签即可。
